# 足し算忍者から幻獣ハンターへの移植

移植元: `keisan` のコミット `5c67ae3`。入口は `hikizan_hunter.html` に統一し、旧 `hikizan.html` はクエリー・ハッシュを保持して転送する。

## 移植したもの

- 学習設定（マスター判定時間）、暗唱練習、協力バトル、横画面レイアウト。
- `js/ninja/` の演出設定、ボタン演出、全問正解、実績獲得、キャラクター進化。元の実装を取り込み、表示と画像をハンターに接続。
- 元の商店・デバッグエンジンを `hunter-shop-debug.js` に移植。商品は幻獣・探索道具に置き換え、保存先を引き算用に分離。
- `model/` は元フォルダーを丸ごとコピー。TensorFlow.js 4.22.0 も `vendor/` に同梱し、モデル読み込みを CDN に依存させない。

## 引き算側で保持・修正したもの

- 引き算の出題（0の答えを含む）、10から引く練習、繰り下がり、ドット／そろばんの2種類のヒント、35枚のコツメダル、通常5枚のメダル、ハンターの4段階進化と画像。
- 結果 → ★付与 → 全問正解 → 新規メダル → 進化の接続。獲得済みメダルを保存し、後日の間違いで消えないようにした。
- 二重回答・二重報酬を防止。画面移動や次問で古いヒント／手書き／進行タイマーを取り消す。
- コツ練習の苦手フィルターと記録画面、音・演出設定の保存、セーブの書き出し／読み込み。
- 旧版の `tashizan_*` 記録から「引き算の式」のみ一度移行。既存のハンター記録を優先し、元データを削除しない。

## デバッグ

「せってい」→「こうどな せってい」のアイコンを10秒長押し。移植元と同じパスワード `16801680`。★、実績、購入状態、自動獲得を確認できる。これは開発・確認用のUIであり、セキュリティ上の認証ではない。

## テスト

Playwright と Chromium/Edge が必要。`PLAYWRIGHT_MODULE` にインストール済み Playwright のパスを指定できる。

```text
node tests/run.cjs
```

ローカル8874番ポートでテスト用サーバーを起動し、6本の回帰テストを実行する。

- `model`: ローカルの実モデルで描画した0を認識、推論時のテンソル解放。
- `learning`: 5画面サイズ × 3入力方式 × 2ヒント、暗唱全モード、途中終了、二重回答防止、設定保存。
- `progression`: 実際の10秒長押し解除、購入、報酬、メダル保持、連続演出、進化、設定、保存、参照画像。
- `hints`: 減加法／減減法、10からの引き算、そろばん、旧タイマー取り消し、記録、リセット分離。
- `raid`: Firebaseを模擬した接続・ダメージ・失敗・切断・期限切れ。実サービスへの対戦接続は未検証。
- `migration`: 旧URL、引き算記録だけの移行、既存設定保持、不正バックアップ拒否。

テスト画像は `tests/*.png` に出力し、Git管理対象外。公開環境への反映は別途必要。
