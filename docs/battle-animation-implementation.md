# 引き算幻獣ハンター：バトル演出の実装

実装日：2026-10-03。仕様は [battle-animation-plan.md](battle-animation-plan.md)。移植元は足し算版 `92f4d85`。

## 接続と学習処理

- `hikizan_hunter.html` の採点済み回答・通常終了・手書き再入力と、`hunter-challenges.js` の独自採点・終了を接続。
- 通常・コツは実際の問題数で進行。正解でランタンの攻撃、3連続で光の結晶、5連続で強い光の技。誤答で連続数だけをリセットする。
- 通常は誤答を含む完走でも達成を見せる。メダル・マスター条件は従来どおりで、演出から報酬を直接付与しない。
- 神速・超神速は完走で達成、誤答・時間切れ・途中終了で撤退。無限は5正解で1体、16〜20問は上位幻獣、21問から周期を繰り返す。未完了の相手は撃破数に含めない。
- 時計と次問予約を止めた後、通常は直前の攻撃・ダメージを見せてから約2.6秒の終了演出を実行。「結果へ進む」でスキップできる。同じ終了を重ねて呼んでも報酬処理は一度だけ。画面を離れると古い結果予約を破棄する。
- 暗唱を完了した後に終了演出へ進み、従来の結果→報酬→進化を維持。

## 相手と成長

`js/hunter-battle-roster.js` は入口HTMLの `ACH_BADGE_DEFS` と `KOTSU_IMG_DEFS`、正式名の `hunterCreatureName` を参照する。通常7体・神速／超神速8体・コツ35体のキーをそれぞれ固有のスプライトへ接続する。獲得済みの幻獣とも再戦する。

にがてはそのコースの20問の幻獣（10からひくは `ten_all`）。無限は同じコースの幻獣だけを使う。相手を特定できない画面には演出を出さない。

ハンターの成長は引き算の `ACH_STAGES`、実績数0・8・18・28の4段階。報酬画像・図鑑画像は上書きしない。

## 表示と設定

幅960px以上・高さ540px以上・4:3より横長の画面を候補にし、中央教材・回答・ヒントボタンと両端領域の実寸を検査する。中央の式と回答の寸法は保持し、重なる場合は演出を隠す。

通常／ひかえめ／オフは既存の `hikizan_learning_v1` に保存し、ハンターのバックアップにも含める。OSの動きを減らす設定では待機・オーラを停止する。ヒント（ドット・減加法／減減法・そろばん・さくらんぼ）、暗唱、画面非表示中も停止し、隠れていた間の攻撃を後で再生しない。通常の攻撃・被弾は850ms、5連続の技は1100msで、次問予約もこれを待つ。

「ミスしたあとの解説」は初期値ON。ダメージを見せた後にドット／減加法の解説を出し、図と音声の全段階を終えて最後の答えを見せてから「わかった！ つぎへ」を有効にする。OFFでは従来の自動進行。神速の誤答・時間切れでも、解説を最後まで見てから撤退結果へ進む。途中で画面を移動すると古い解説予約を破棄する。設定は同じ保存・バックアップに含まれる。

問題タイマーは小数1桁を保持し、開始時は0.0、制限秒数も5.0などと表示する。等幅数字の指定で桁の更新による幅の揺れを抑える。

装飾は読み上げ対象外で、入力を遮らず、戦闘音を追加しない。PNG読み込みや描画が失敗しても学習と結果処理は続ける。

## 素材の記録とプレビュー

- 配置先：`img/battle/`。
- 生成方式：組み込み `image_gen`。参照画像・生成プロンプト・生成元・配置先は [battle-art-manifest.json](battle-art-manifest.json)。
- 元シートはハンター4列×7行、幻獣4列×5行。読み取り時は各行・各コマの透明な余白から可変の境界を探す。隣り合う光が連結した箇所は、光の最も薄い部分を選ぶ。体・角・翼を固定グリッドで切らないための処理で、元シートの境界判断を [battle-sprite-boundaries.json](battle-sprite-boundaries.json) に記録した。正規化後は64pxセル、透明背景、足元を統一、最近傍描画。
- [battle-art-preview.html](battle-art-preview.html) は全素材の動作・元シート・参照画像を確認するページ。
- `scripts/normalize-hunter-battle.cjs` は描画時と同じ64pxセルにパックする。生成元の高解像度PNGは記録した元パスに保持する。

## 検証

専用テスト：`node tests/run.cjs battle battle-assets battle-review`。`NODE_PATH` にPlaywrightのインストール先を設定して実行する。報酬や暗唱を独立して検証する既存テストでは、新しい演出・ミス解説をOFFにする。

既存テスト15種類を実行し、`model`・`learning`・`hints`・`migration`・`creatures`・`challenges`・`challenge-layout`・`speed-badges` は通過。`progression`・`raid`・`refresh`・`home-fit`・`mix`・`requested-changes`・`flow` の7件は旧メニュー／レイアウトの前提などで失敗した。Gitの変更前のHTMLと挑戦処理を配信した比較でも、同じ7件が同じ箇所で失敗した。これらを今回のバトル追加による回帰とは扱わない。

最終検査：バトル・全素材・解説の専用テストを通過。全54シート（幻獣50・ハンター4）の読み込み、透明背景、必須コマ、正規化セル内の余白を検査し、待機・攻撃一覧と終了した解説を目視確認した。生成PNG合計158,497,589バイトを7,295,433バイトにパック。高解像度の生成元はマニフェストの元パスに保持。既存の8種類も変更後に再度通過した。
